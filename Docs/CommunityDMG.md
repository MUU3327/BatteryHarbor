# 未公证社区 DMG

电池港的社区 DMG 是供早期测试者使用的自签名构建，不经过 Apple 公证。它不是 Mac App Store 软件，也不会要求用户关闭 Gatekeeper 或 SIP。

## 安装

1. 从项目官方 GitHub Releases 下载带有 `unnotarized` 的 DMG。
2. 打开 DMG，将 `Battery Harbor.app` 拖入 `Applications`。
3. 第一次尝试打开电池港。macOS 会因为构建未经 Apple 公证而阻止启动。
4. 前往“系统设置 → 隐私与安全性”，在“安全性”区域点击“仍要打开”。
5. 再次确认打开电池港。

不要全局关闭 Gatekeeper，不要关闭 SIP，也不要运行来源不明的 `sudo` 安装命令。

## 启用充电控制

1. 打开“电池港设置 → 充电”。
2. 点击注册或更新控制模块。
3. 按界面提示前往“系统设置 → 通用 → 登录项与扩展”，批准电池港后台控制模块。
4. 返回电池港并测试连接。
5. 阅读安全提示后，由本人点击“开始安全自检”。
6. 只有出现“写入、回读和恢复验证已通过”后，才测试暂停、恢复或充电上限。

安全自检会短暂切换受白名单保护的充电控制值，然后回读并恢复原值。Helper 或 Mac 重启后会重新锁定硬件写入。

## 升级

1. 在“设置 → 充电”点击“移除模块”。
2. 退出旧版电池港。
3. 用新版 App 替换 Applications 中的旧版。
4. 启动新版并重新注册、批准和执行安全自检。

首个社区预览版不保证 Helper 可以在所有 macOS 与 Mac 型号上原位升级。

## 卸载

1. 在“设置 → 充电”点击“移除模块”，确认 Helper 不再显示为已启用。
2. 关闭“登录时启动电池港”。
3. 退出电池港。
4. 将 Applications 中的 `Battery Harbor.app` 移到废纸篓。
5. 如果系统设置仍显示旧的后台项目，重新登录或重启 Mac 后再次检查。

## 已知限制

- 构建未经 Apple Developer ID 签名和公证，首次打开需要人工批准。
- 当前仅验证 Apple Silicon Mac，兼容性矩阵仍在建立。
- 自签名 root Helper 已在一台无 Apple ID、无维护者证书的干净临时管理员账号中验证；其他 Mac 型号和 macOS 版本仍需社区反馈。
- “超出上限时自动放电”属于实验功能，首个预览版建议保持关闭。
- Helper 允许恢复充电后，macOS 可能需要几十秒到约一分钟才恢复实际电池输入；期间保持适配器连接且没有主动放电即属正常。

## 维护者签名证书

每个社区 DMG 必须使用同一张 `Battery Harbor Open Source Release` 证书签名 App 与 Helper。维护者应将包含私钥的加密 `.p12` 备份保存在仓库之外；不得把证书私钥、备份密码或未加密密钥提交到 GitHub。丢失私钥后，后续版本无法继续证明与此前社区构建来自同一签名身份。
