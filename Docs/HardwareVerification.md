# 充电控制安全自检

电池港不会通过一个手工勾选框解锁 SMC 控制。root Helper 每次启动后都必须完成一次短暂、可恢复的 `CHTE` 自检；Helper 在自检通过前会拒绝所有充电命令。

## 自检执行内容

1. 读取 `CHTE` 原始值，并要求它严格等于已知的启用值 `[0, 0, 0, 0]` 或暂停值 `[1, 0, 0, 0]`。
2. 短暂写入相反状态并立即回读。
3. 写回原始值。
4. 再次回读并确认与原始值完全一致。

未知原值不会触发任何写入。临时写入、首次回读、恢复写入或最终回读任一步失败，Helper 都保持锁定；异常路径也会再次尝试恢复原值。

## 实机验证前提

- 在 Xcode 的 Accounts 中登录 Apple ID。
- 为 `BatteryHarbor` 和 `BatteryHarborHelper` 选择同一个 Personal Team 或 Developer Team。
- 从 Xcode 运行完整 `.app`，不要使用 `swift run`。
- 连接电源适配器。
- 退出其他会修改充电状态的电池管理工具。

## 操作步骤

1. 打开电池港设置的“充电管理”。
2. 安装控制模块；如果显示等待批准，前往“系统设置 → 通用 → 登录项”批准。
3. 点击“测试连接”，确认界面显示 `root`、写入后端可用且协议为 v3。
4. 点击“开始安全自检”。
5. 只有界面显示 `原值 → 临时值 → 恢复值` 且首尾完全相等时，控制按钮才会解锁。

Helper 或 Mac 重启后需要重新执行自检。这可以避免旧确认状态跨越新的 Helper 进程。

## 失败处理

- 不要继续尝试暂停、放电或校准。
- 点击“重新锁定硬件控制”。
- 在“高级”中导出诊断报告。
- 在“充电管理”中移除控制模块。
- 保留失败时的原值、临时值和错误信息，用于兼容性分析。
